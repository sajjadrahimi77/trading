# پروژه مستقل آموزش معامله

این پروژه از فایل‌های ارسالی ساخته شده و صفحه آن در `/trading/tutorial` قرار دارد. ریشه سایت به همان صفحه هدایت می‌شود. برای آموزش‌های بعدی مسیرهای جدا اضافه کنید. نمونه برای استقرار: `https://learn.example.com/trading/tutorial`؛ نام دامنه نمونه است.

## اجرا

Node.js سازگار با Next.js 16 و npm لازم است. پوشه پروژه را باز کرده و اجرا کنید:

```powershell
npm install
Copy-Item .env.example .env.local
npm run dev -- --port 3001
```

سپس `http://localhost:3001/trading/tutorial` را باز کنید. برای انتشار: `npm run build` و سپس `npm run start -- --port 3001`. این پروژه route handler دارد و نیازمند اجرای سرور Next.js است. نسخه‌ها در package.json اولیه‌اند و lockfile ارائه نشده؛ مسئول استقرار باید نسخه‌ها را بررسی و lockfile تولید کند.

## تنظیمات برای برنامه‌نویس

- `AUTOMARKETING_INTERNAL_BASE_URL`: آدرس قابل دسترس از سرور Next.js به بک‌اند اتومارکتینگ، بدون `/api`؛ localhost فقط در صورتی درست است که اتومارکتینگ در همان محیط شبکه باشد.
- `TUTORIAL_PUBLIC_ORIGIN`: آدرس دقیق عمومی آموزش با پروتکل، بدون مسیر و بدون اسلش پایانی؛ مثلاً `https://learn.example.com`.
- `ECOCOACH_TRADING_API_KEY`: کلید سمت سرور برای دریافت دفتر سفارش واقعی؛ در فایل عمومی و گیت ثبت نشود. بدون کلید یا هنگام خطای سرویس، مسیر سفارش داده نمونه برمی‌گرداند (`data_source: mock`).
- متغیرهای واقعی را در محیط سرور تنظیم کنید. بعد از انتخاب ساب‌دامین، مقصد `automarketing.tracking.destinations.first_order_training` را روی آدرس همین صفحه تنظیم کنید. نام آموزش با کاربرد journey و متن پیامک تطبیق داده شود؛ این صفحه آموزش معامله است، نه لزوماً آموزش واریز.
- این فایل‌ها سامانه ساخت لینک کوتاه یا اتصال SignalAds را پیاده‌سازی نمی‌کنند. لینک اختصاصی کاربر و توکن معتبر باید توسط سامانه موجود فراهم شود. کد صفحه توکن ۶۴ کاراکتری hex را از `#t=` یا `?t=` می‌خواند. مسیر انتقال توکن و سازگاری آن با ریدایرکت واقعی باید آزمایش شود؛ توکن را برای آزمایش یا خروجی لاگ عمومی منتشر نکنید.
- رخدادها از مسیر `/api/tutorial/events` به اتومارکتینگ منتقل می‌شوند. ثبت و دسته‌بندی در اتومارکتینگ انجام می‌شود و گزارش CRM وابسته به تنظیمات موجود است. Secret مربوط به CRM در مرورگر قرار نگیرد.
- تصاویر ارسالی در `public/images/trading` هستند. صفحه اصلی و CSS آموزش از فایل‌های ارسالی هستند؛ layout و تنظیمات پروژه برای مستقل‌سازی جدید هستند و ممکن است ظاهر با محیط اصلی کمی متفاوت باشد.

## وضعیت بررسی و تحویل

تست‌های PHPUnit گزارش‌شده توسط کاربر ۵ مورد موفق داشتند، اما پروژه مستقل و اتصال انتها به انتها هنوز در سرور مقصد تست نشده‌اند. مسئول فنی باید build، نمایش در موبایل و دسکتاپ، اتصال واقعی order-book، لینک شخصی دو کاربر، ثبت page_opened/started/completed، صف پردازش، دسته‌بندی و گزارش CRM را با داده آزمایشی بررسی کند. دیدن کامل صفحه معادل اثبات یادگیری نیست.

در این نسخه نشانگر مرحله ورود قیمت در وسط لبه بالایی کادر قرار گرفته تا عدد پوشانده نشود. رنگ کادرها و دکمه‌های آموزش نیز به سبز واضح‌تر تغییر کرده است. بررسی ظاهری روی دستگاه مقصد ضروری است.
